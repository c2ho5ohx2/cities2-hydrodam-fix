# Changelog

## 0.1.0 - 2026-09-18

Initial release.

- Fixes hydroelectric dams producing 0 MW in Cities: Skylines II 1.6.2f1.
- Fixes incorrect Low Water Level penalties caused by the affected water-flow CPU readback.
- Restores hydroelectric dam placement power estimates.
- Restores river-flow-based dam orientation.
- Adds compatibility guards so the mod does nothing when the known regression is not present.
